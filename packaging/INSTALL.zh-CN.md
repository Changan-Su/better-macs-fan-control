# 安装 Better Fan

系统要求：macOS 13 或更新版本。按设备架构下载 arm64（Apple 芯片）或 x86_64（Intel）版本。

1. 打开 DMG，将 Better Fan 拖入“应用程序”文件夹；ZIP 则先解压再拖入。
2. 打开应用。它默认读取真实风扇和温度信息，不自动申请后台控制权限。
3. 已签名版本可在总览中点击“启用风扇控制”，按系统提示允许后台服务后返回应用。
4. 选择风扇及模式，预览后点击“应用设置”。恢复系统自动会将本应用控制的风扇交回 macOS。

## 当前预览构建

文件名包含 `unsigned-monitor` 的构建只进行 ad-hoc 签名，未通过 Developer ID 签名和 Apple 公证。它支持真实监测，但不会启用特权控制服务。macOS 可能阻止未公证应用运行；请仅在你信任来源时按系统“隐私与安全性”中的提示处理，不需要关闭系统安全功能。

当前版本为 alpha。机型、系统版本和固件会影响 SMC 兼容性。无法读取的数据保持空缺，不会用模拟读数代替；控制写入或恢复失败会显示错误。

## 关闭与卸载

关闭窗口会隐藏到菜单栏。退出应用前会请求恢复本应用的风扇设置；失去连接、心跳超时、睡眠或系统热压力升高时，辅助服务也会尝试恢复自动。硬件拒绝写入时无法保证恢复成功，应留意界面错误。

已启用辅助服务时，先恢复系统自动，并在系统“登录项与扩展”中停用 Better Fan 后再将应用移至废纸篓。监测版不会安装辅助服务。
